\# 🛍️ E-Commerce PWA



A responsive and offline-ready \*\*E-Commerce Progressive Web App (PWA)\*\* built using HTML, CSS and JavaScript.



This project provides a complete basic shopping experience with product browsing, search, categories, sorting, product details, wishlist, cart management, authentication, checkout and order management.

\## 🚀 How to Run



Clone the repository:



```bash

git clone https://github.com/Pavithrapavi25/ecommerce-pwa.git

```



Open the project folder:



```bash

cd ecommerce-pwa

```



Start a local server:



```bash

python -m http.server 5500

```



Open the application in your browser:



```text

http://localhost:5500

```
